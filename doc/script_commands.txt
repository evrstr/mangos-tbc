The action to execute.

## datalong / 长整型参数（datalong, datalong2, datalong3）
-- --------------------------

3 multipurpose fields, store raw data as unsigned values
3 个多用途字段，以无符号整数（unsigned）形式存储原始数据

-- --------------------------
## buddy_entry / 协同对象条目（buddy_entry）
-- --------------------------

1 field to store the entry of a "buddy" (depending on command can be both GameObject and Creature entry)
用于存储“协同对象（buddy）”的 entry（根据命令不同，可以是游戏对象或生物的 entry）

-- --------------------------
## search_radius / 搜索半径（search_radius）
-- --------------------------

Range in which the buddy defined in buddy_entry will be searched
搜索 buddy_entry 所指定协同对象的范围半径
In case of SCRIPT_FLAG_BUDDY_BY_GUID this field is the buddy's guid!
若设置了 SCRIPT_FLAG_BUDDY_BY_GUID，则此字段表示协同对象的 GUID！
In case of SCRIPT_FLAG_BUDDY_BY_POOL this field is the buddy's pool id!
若设置了 SCRIPT_FLAG_BUDDY_BY_POOL，则此字段表示协同对象的刷新池 ID（pool id）！

-- --------------------------
## data_flags / 数据标志位（data_flags）
-- --------------------------

Field which holds a combination of these flags:
存储以下标志位组合的字段（按位或组合）：

    SCRIPT_FLAG_BUDDY_AS_TARGET             = 0x01      (将协同对象作为目标)
    SCRIPT_FLAG_REVERSE_DIRECTION           = 0x02      (反转源与目标方向)
    SCRIPT_FLAG_SOURCE_TARGETS_SELF         = 0x04      (源对象以自身为目标)

    SCRIPT_FLAG_COMMAND_ADDITIONAL          = 0x08      (Only for some commands possible / 仅部分命令支持的附加行为标志)
    SCRIPT_FLAG_BUDDY_BY_GUID               = 0x10      (Interpret search_radius as buddy's guid / 将 search_radius 解释为协同对象的 GUID)
    SCRIPT_FLAG_BUDDY_IS_PET                = 0x20      (Do not search for an npc, but for a pet / 搜索宠物而非普通 NPC)
    SCRIPT_FLAG_BUDDY_IS_DESPAWNED          = 0X40      (Search for a buddy that is dead or despawned / 搜索已死亡或已消失的协同对象)
    SCRIPT_FLAG_BUDDY_BY_POOL               = 0x80      (buddy should be part of a pool / 协同对象须属于指定刷新池)
    SCRIPT_FLAG_BUDDY_BY_SPAWN_GROUP        = 0x100,    (buddy is from spawn group - NYI - TODO: / 协同对象来自刷新组 - 尚未实现)
    SCRIPT_FLAG_ALL_ELIGIBLE_BUDDIES        = 0x200,    (multisource/multitarget - will execute for each eligible / 多源/多目标模式 —— 对所有符合条件的协同对象逐一执行)
    SCRIPT_FLAG_BUDDY_BY_GO                 = 0x400,    (take the buddy by GO (for commands which can target both creature and GO) / 以游戏对象作为协同对象，用于同时支持生物和 GO 的命令)
    SCRIPT_FLAG_BUDDY_BY_STRING_ID          = 0x800,    (takes buddy from string id - creature or go / 通过 string_id 获取协同对象 —— 生物或游戏对象)

Detailed meaning described below!
详细含义见下文说明！

## dataint / 有符号整型参数（dataint, dataint2, dataint3, dataint4）
-- --------------------------

4 multipurpose fields, store raw data as signed values
4 个多用途字段，以有符号整数（signed）形式存储原始数据
Note: used for text ids SCRIPT_COMMAND_TALK (0),
      for emote ids in SCRIPT_COMMAND_EMOTE (1),
      for spell ids in SCRIPT_COMMAND_CAST_SPELL (15)
      and as waittime with SCRIPT_COMMAND_TERMINATE_SCRIPT (31)
注：常用于 SCRIPT_COMMAND_TALK (0) 的文本 ID、SCRIPT_COMMAND_EMOTE (1) 的表情 ID、
    SCRIPT_COMMAND_CAST_SPELL (15) 的法术 ID，以及 SCRIPT_COMMAND_TERMINATE_SCRIPT (31) 的等待时间。

## Buddy concept / 协同对象（Buddy）概念
-- --------------------------

Commands except the ones requiring a player (like KILL_CREDIT) have support for the buddy concept.
This means that if an entry for buddy_entry is provided,
aside from source and target as listed above also a "buddy" is available.
除必须以玩家为目标的命令（如 KILL_CREDIT）外，其余命令均支持“协同对象（buddy）”机制。
这意味着只要提供了 buddy_entry，除了上述原始源（originalSource）和原始目标（originalTarget）之外，还可以使用第三个对象“buddy”。

Which one on the three (originalSource, originalTarget, buddy) will be used in the command, depends on the data_flags
Note that some commands (like EMOTE) use only the resulting source for an action.
命令最终使用这三者（originalSource、originalTarget、buddy）中的哪两个作为执行方与目标，取决于 data_flags 的设置。
注意：部分命令（如 EMOTE）在执行动作时仅使用最终的源对象（resultingSource）。

Possible combinations of the flags
    SCRIPT_FLAG_BUDDY_AS_TARGET             = 0x01
    SCRIPT_FLAG_REVERSE_DIRECTION           = 0x02
    SCRIPT_FLAG_SOURCE_TARGETS_SELF         = 0x04
are:
上述三个方向控制标志的可能组合如下：
0: originalSource / buddyIfProvided  ->  originalTarget
   （原始源对象，若提供 buddy 则为 buddy  ->  原始目标对象）
1: originalSource  ->  buddy
   （原始源对象  ->  协同对象）
2: originalTarget  ->  originalSource / buddyIfProvided
   （原始目标对象  ->  原始源对象，若提供 buddy 则为 buddy）
3: buddy  ->  originalSource
   （协同对象  ->  原始源对象）
4: originalSource / buddyIfProvided  ->  originalSource / buddyIfProvided
   （原始源对象或 buddy  ->  自身）
5: originalSource  ->  originalSource
   （原始源对象  ->  原始源对象）
6: originalTarget  ->  originalTarget
   （原始目标对象  ->  原始目标对象）
7: buddy  ->  buddy
   （协同对象  ->  协同对象）
Where "A  ->  B" means that the command is executed from A with B as target.
其中 “A  ->  B” 表示命令由 A 发起，以 B 作为目标执行。

Defining a buddy could be done in several way:
指定协同对象可通过以下多种方式完成：
    default                                         (take the buddy by entry / 默认：按 entry 查找协同对象)
    SCRIPT_FLAG_BUDDY_BY_GUID               = 0x10  (take the buddy by guid / 按 GUID 查找协同对象)
    SCRIPT_FLAG_BUDDY_IS_PET                = 0x20  (buddy is a pet / 协同对象为宠物)
    SCRIPT_FLAG_BUDDY_IS_DESPAWNED          = 0x40  (buddy is dead or despawned / 协同对象已死亡或已消失)
    SCRIPT_FLAG_BUDDY_BY_POOL               = 0x80  (buddy should be part of a pool / 协同对象属于指定刷新池)
    SCRIPT_FLAG_BUDDY_BY_STRING_ID          = 0x800 (buddy should be part of a spawn group / 通过 string_id 或刷新组匹配协同对象)

 0 SCRIPT_COMMAND_TALK                      resultingSource = WorldObject, resultingTarget = Unit/none
                                            [说话/喊话] 最终源 = WorldObject，最终目标 = Unit/无
                                            * datalong = dbscript_string_template ID - will randomize between all dbscript_strings in given template, ids from template are checked against dbscript_string table
                                              datalong = dbscript_string_template ID —— 从指定模板的全部 dbscript_string 中随机选取一条，模板中的 ID 会对照 dbscript_string 表校验
                                            * dataint = text entry from dbscript_string -table. dataint2-dataint4 optionally, for random selection of text
                                              dataint = dbscript_string 表中的文本条目 ID。dataint2-dataint4 可选，用于随机选取多条文本之一

 1 SCRIPT_COMMAND_EMOTE                     resultingSource = Unit, resultingTarget = Unit/none
                                            [做动作/表情] 最终源 = Unit，最终目标 = Unit/无
                                            * datalong = emote_id (表情 ID)
                                            * dataint1-dataint4 optionally, for random selection of emote (可选，用于随机选取表情之一)

 2 SCRIPT_COMMAND_FIELD_SET                 source = any
                                            [设置对象字段值] source = 任意对象
                                            * datalong = field_id (字段索引 ID)
                                            * datalong2 = field value (要设置的字段值)

 3 SCRIPT_COMMAND_MOVE_TO                   resultingSource = Creature
                                            [移动到指定位置] 最终源 = Creature
                                            If position is very near to current position, or x=y=z=0, then only orientation is changed
                                            若目标位置非常接近当前位置或 x=y=z=0，则仅改变朝向
                                            * datalong = dbscripts_on_relay id - executed for source and target same as this script
                                              datalong = dbscripts_on_relay 脚本 ID —— 到达后执行，源和目标沿用当前脚本
                                            * datalong2 = 0x2 make it main movegen and persist through combat evade
                                              datalong2 = 0x2 使其成为主移动生成器并在脱战返回（evade）后保持
                                            * datalong3 = enum ForcedMovement (强制移动方式枚举 ForcedMovement)
                                            * data_flags & SCRIPT_FLAG_COMMAND_ADDITIONAL: teleport unit to position
                                              若设置 SCRIPT_FLAG_COMMAND_ADDITIONAL：直接将单位传送至目标位置
                                            * x/y/z/o (目标坐标与朝向)
                                            * dataint = 1 to init move to respawn position, 2 to init creature group member each in their respawn position.
                                                        no other data is needed. So ex: command 3 ... dataint=1 and creature should head to its respawn pos
                                              dataint = 1 时移动至自身重生点；2 时令生物组内各成员分别移动至各自的重生点（无需其他坐标数据）

 4 SCRIPT_COMMAND_FLAG_SET                  source = any
                                            [设置标志位] source = 任意对象
                                            * datalong = field_id (字段索引 ID)
                                            * datalong2 = bitmask (要置位的位掩码)

 5 SCRIPT_COMMAND_FLAG_REMOVE               source = any
                                            [移除标志位] source = 任意对象
                                            * datalong = field_id (字段索引 ID)
                                            * datalong2 = bitmask (要清除的位掩码)

 6 SCRIPT_COMMAND_TELEPORT_TO               source or target with Player
                                            [传送玩家] 源或目标须包含玩家
                                            * datalong = map_id (目标地图 ID)
                                            * x/y/z (目标坐标)

 7 SCRIPT_COMMAND_QUEST_EXPLORED            one from source or target must be Player, another GO/Creature
                                            [完成任务探索目标] 源或目标之一须为玩家，另一方为 GO 或生物
                                            * datalong = quest_id (任务 ID)
                                            * datalong2 = distance or 0 (有效距离，0 表示不限)

 8 SCRIPT_COMMAND_KILL_CREDIT               source or target with Player
                                            [给予任务击杀计数] 源或目标须包含玩家

                                              datalong = 生物 entry，若为 0 则自动使用源或目标生物的 entry
                                            * datalong2 = bool (0=personal credit, 1=group credit / 0=仅个人获得，1=全队共享)

 9 SCRIPT_COMMAND_RESPAWN_GAMEOBJECT        source = any, target = any
                                            [刷新游戏对象] source = 任意，target = 任意

                                              dataint4 = 若 > 0，则使用 creature_spawn_data_template 表中的配置

                                            * datalong = spell id (法术 ID)
                                            * datalong2 = TriggerCastFlags (触发施法标志 TriggerCastFlags)
                                            * dataint1-dataint4 optional. If some of these are set to a spell id, a random spell out of datalong, datint1, ..,dataintX is cast.
                                              dataint1-dataint4 可选。若设为法术 ID，则从 datalong 及 dataint1..dataintX 中随机选取一个施放
                                            * data_flags & SCRIPT_FLAG_COMMAND_ADDITIONAL: do not pass target to spellcast

16 SCRIPT_COMMAND_PLAY_SOUND                source = any object, target=any/player
                                            [播放音效/音乐] source = 任意对象，target = 任意/玩家

                                            * datalong2 (bitmask: 0/1=target-player, 0/2=with distance dependent, 0/4=map wide, 0/8=zone wide, 0/16=area wide;

                                              例如 1|2 = 3 表示对目标播放且受距离影响；8 与 16 不能同时使用

                                            * data_flags & SCRIPT_FLAG_COMMAND_ADDITIONAL: remove the item from player by the given amount

                                            * datalong = despawn delay (消失延迟时间，毫秒)

20 SCRIPT_COMMAND_MOVEMENT                  resultingSource = Creature
                                            [设置生物移动模式] 最终源 = Creature
                                            * datalong = MovementType (0:idle, 1:random, 2:waypoint, 3:path, 4:linear, 18:fall)
                                              datalong = 移动类型（0:待机，1:随机漫步，2:路径点，3:样条路径，4:直线路径，18:坠落）
                                            * datalong2 = wanderDistance (for random movement), pathId (for waypoint movement), relayId (for fall movement)
                                              datalong2 = 随机漫步半径（random）、路径 ID（waypoint）、落地后触发的 relayId（fall）
                                            * datalong3 = 0x1 - timer for timed random movement or pass target to waypoint and path movegen (by default, source targets self)
                                                          0x2 - for waypoint, path and linear path - uses pathId from waypoint_path table
                                                          0x4 - for path - flying specifier
                                                          0x8 - for path - cyclic specifier
                                              datalong3 标志：0x1 定时随机移动时长或向路径生成器传入目标（默认以自身为目标）；
                                                              0x2 对 waypoint/path/linear 强制使用 waypoint_path 表的 pathId；
