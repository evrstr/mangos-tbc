===========================================================================
MaNGOS EventAI (Creature_AI) Documentation: (Last Updated: June 25, 2018)
MaNGOS EventAI (Creature_AI) 文档：（最后更新：2018年6月25日）
===========================================================================

EventAI allows users to create new creature scripts entirely within the database.
EventAI 允许用户完全在数据库中创建新的生物（Creature）脚本。

For the AI to be used, you must first make sure to set AIname for each creature that should use this AI.
要启用该 AI，必须先为需要使用 EventAI 的每个生物设置 AIName 字段：
UPDATE creature_template SET AIName = 'EventAI' WHERE entry IN (...);

Note: Edit in Spaces, not Tabs
注意：请使用空格（Spaces）而非制表符（Tabs）进行编辑。

=========================================
Basic Structure of EventAI / EventAI 基本结构
=========================================

EventAI follows a basic IF (Event) then DO (Action) format.
Below is the list of current fields of the creature_ai_scripts table.
EventAI 遵循基本的“IF（事件触发）then DO（执行动作）”格式。
以下为 creature_ai_scripts 表的当前字段列表。

Field_Name                      Description
-------------------------------------------
id                              This value is merely an incrementing counter of the current Event number. Required for sql queries. (ACID Standards: CreatureID+Additional 2 digit Incriment Starting with 01)
                                当前事件编号的自增计数 ID，用于 SQL 查询。（ACID 标准：CreatureID 后接从 01 开始的两位递增数字）
creature_id                     Creature ID which should trigger this event (This is entry value from `creature_template` table).
                                应触发此事件的生物 ID（对应 `creature_template` 表的 entry 值）。

event_type                      The type of event you want to script. (see "Event Types" below for different values)
                                要编写的事件类型。（具体数值见下文“Event Types / 事件类型”）
event_inverse_phase_mask        Mask with phases this event should NOT trigger in* (See footnote for more details on using any other value then 0)
                                反向阶段掩码：指定此事件**不应**在哪些阶段触发*（使用非 0 值时详见下方脚注说明）
event_chance                    Percentage chance of triggering the event (1 - 100)
                                事件触发的百分比几率（1 - 100）
event_flags                     Event Flags (Used to select Repeatable or Dungeon Heroic Mode)... See "Event Flags" Below For Defined Values
                                事件标志（用于设置可重复或地下城英雄模式等）……定义值见下文“Event Flags / 事件标志”
event_param1                    Variables for the event (depends on event_type) / 事件参数 1（含义取决于 event_type）
event_param2                    Variables for the event (depends on event_type) / 事件参数 2（含义取决于 event_type）
event_param3                    Variables for the event (depends on event_type) / 事件参数 3（含义取决于 event_type）
event_param4                    Variables for the event (depends on event_type) / 事件参数 4（含义取决于 event_type）
event_param5                    Variables for the event (depends on event_type) / 事件参数 5（含义取决于 event_type）
event_param6                    Variables for the event (depends on event_type) / 事件参数 6（含义取决于 event_type）

action1_type                    Action #1 to take when the Event occurs (see "Action types" below) / 事件发生时执行的动作 #1（见下文“Action Types / 动作类型”）
action1_param1                  Variables used by Action1 (depends on action_type) / 动作 1 参数 1（含义取决于 action_type）
action1_param2                  Variables used by Action1 (depends on action_type) / 动作 1 参数 2（含义取决于 action_type）
action1_param3                  Variables used by Action1 (depends on action_type) / 动作 1 参数 3（含义取决于 action_type）

action2_type                    Action #2 to take when the Event occurs (see "Action types" below) / 事件发生时执行的动作 #2（见下文“Action Types / 动作类型”）
action2_param1                  Variables used by Action1 (depends on action_type) / 动作 2 参数 1（含义取决于 action_type）
action2_param2                  Variables used by Action1 (depends on action_type) / 动作 2 参数 2（含义取决于 action_type）
action2_param3                  Variables used by Action1 (depends on action_type) / 动作 2 参数 3（含义取决于 action_type）

action3_type                    Action #3 to take when the Event occurs (see "Action types" below) / 事件发生时执行的动作 #3（见下文“Action Types / 动作类型”）
action3_param1                  Variables used by Action1 (depends on action_type) / 动作 3 参数 1（含义取决于 action_type）
action3_param2                  Variables used by Action1 (depends on action_type) / 动作 3 参数 2（含义取决于 action_type）
action3_param3                  Variables used by Action1 (depends on action_type) / 动作 3 参数 3（含义取决于 action_type）

All params are signed 32-bit values (+/- 2147483647). Time values are always in milliseconds.
In case of a percentage value, use value/100 (ie. param = 500 then that means 500%, -50 = -50%)
所有参数均为有符号 32 位整数（+/- 2147483647）。时间值单位始终为毫秒（ms）。
涉及百分比值时以 100 为基准（例如 param = 500 表示 500%，-50 表示 -50%）。

[*] Phase mask is a bitmask of phases which shouldn't trigger this event. (ie. Phase mask of value 12 (binary 1100) results in triggering this event in phases 0, 1 and all others with exception for phases 2 and 3 (counting from 1 as Phase 0 = 1).
[*] Phase 0 is default so this will occur in all phases unless specified. (1101 = Triggers in Phase 1, 1011 = Triggers in Phase 2, 0111 = Triggers in Phase 3, 0011 = Triggers in Phase 2 and 3).
[*] Take Desired Binary Configuration and convert into Decimal and this is your event_inverse_phase_mask to use in your script.
[*] 阶段掩码（Phase mask）是一个位掩码，表示**不应**触发该事件的阶段。（例如：值为 12（二进制 1100）表示该事件在阶段 0、1 及除阶段 2、3 以外的所有阶段触发；从低位起阶段 0 = 1）。
[*] 阶段 0 为默认阶段，未指定时将在所有阶段触发。（二进制 1101 = 仅在阶段 1 触发，1011 = 仅在阶段 2 触发，0111 = 仅在阶段 3 触发，0011 = 仅在阶段 2 和 3 触发）。
[*] 将所需的二进制配置转换为十进制，即可得到脚本中应填入的 event_inverse_phase_mask。

=========================================
Event Types / 事件类型总览
=========================================

This is the list of available Event Types EventAI is able to handle.
Each event type has its own specific interpretation of the params that accompany it.
Params are always read in the ascending order (from Param1 to Param3).
以下是 EventAI 可处理的可用事件类型列表。
每种事件类型对其附带参数都有各自特定的解释，参数始终按升序读取（Param1 至 Param3 及后续）。

NOTE: Events will not repeat until the creature exits combat or unless EFLAG_REPEATABLE value is set in Event Flags.
Some events such as EVENT_T_AGGRO, EVENT_T_DEATH, EVENT_T_SPAWNED, and EVENT_T_EVADE cannot repeat even if EFLAG_REPEATABLE value is set.
注意：除非生物退出战斗或事件标志中设置了 EFLAG_REPEATABLE，否则事件不会重复触发。
部分事件（如 EVENT_T_AGGRO、EVENT_T_DEATH、EVENT_T_SPAWNED、EVENT_T_EVADE）即使设置了 EFLAG_REPEATABLE 也不会重复触发。

=========================================
Action Types / 动作类型总览
=========================================

This is a list of action types that EventAI is able to handle.
Each event type has it's own specific interpretation of it's params, just like Events.
For all ACTION_T_RANDOM Actions, When a Particular Param is selected for the Event... The SAME Param # is selected for all 3 actions when Event is triggered.
以下是 EventAI 可处理的动作类型列表。
与事件一样，每种动作类型对其参数都有特定解释。
对于所有 ACTION_T_RANDOM 系列动作，当事件触发并随机选中某一个参数槽位时，同一次事件中的 3 个动作会使用**相同的**参数序号（以实现语音和文字等联动）。

==============================================
Event Types: Expanded and Detailed Information
事件类型：扩展与详细说明
==============================================

Note:
COMBAT ONLY - Means that this event will only trigger durring combat.
OUT OF COMBAT ONLY - Means that this event will only trigger while out of combat.
BOTH - This event can trigger both in and out of combat.
说明：
COMBAT ONLY（仅战斗中）—— 表示该事件仅在战斗期间触发。
OUT OF COMBAT ONLY（仅脱战时）—— 表示该事件仅在非战斗状态触发。
BOTH（战斗内外均可）—— 表示该事件在战斗中与脱战后均可触发。

Events that do not have lables on them are events that are directly involved with the in and out of combat state.
未标注以上标签的事件，通常直接与进入/退出战斗状态本身相关。

------------------
0 = EVENT_T_TIMER_IN_COMBAT: (战斗内计时器)
------------------
Parameter 1: InitialMin - Minumum Time used to calculate Random Initial Expire (首次触发的最小随机延迟时间，毫秒)
Parameter 2: InitialMax - Maximum Time used to calculate Random Initial Expire (首次触发的最大随机延迟时间，毫秒)
Parameter 3: RepeatMin  - Minimum Time used to calculate Random Repeat Expire (重复触发的最小随机间隔时间，毫秒)
Parameter 4: RepeatMax  - Maximum Time used to calculate Random Repeat Expire (重复触发的最大随机间隔时间，毫秒)

COMBAT ONLY - Expires first between (Param1) and (Param2) and then between every (Param3) and (Param4) from then on.
This is commonly used for spells that repeat cast during combat (Simulates Spell Cooldown).
[仅战斗中] 首次在 (Param1)~(Param2) 之间触发，此后每隔 (Param3)~(Param4) 重复触发。常用于战斗中周期性施放的法术（模拟技能冷却）。

----------------------
1 = EVENT_T_TIMER_OOC: (脱战计时器)
----------------------
Parameter 1: InitialMin	- Minimum Time used to calculate Random Initial Event Expire (首次触发的最小随机延迟时间，毫秒)
Parameter 2: InitialMax	- Maximum Time used to calculate Random Initial Event Expire (首次触发的最大随机延迟时间，毫秒)
Parameter 3: RepeatMin	- Minimum Time used to calculate Random Repeat Event Expire (重复触发的最小随机间隔时间，毫秒)
Parameter 4: RepeatMax	- Maximum Time used to calculate Random Repeat Event Expire (重复触发的最大随机间隔时间，毫秒)

OUT OF COMBAT ONLY (Not while evading) - Expires first between (Param1) and (Param2) and then between every (Param3) and (Param4) from then on.
This is commonly used for events that occur and repeat outside of combat like random NPC Say or Random Emotes.
[仅脱战时（Evade 期间除外）] 首次在 (Param1)~(Param2) 之间触发，此后每隔 (Param3)~(Param4) 重复触发。常用于脱战状态下的随机对话或随机表情。

---------------
2 = EVENT_T_HP: (自身生命值百分比)
---------------
Parameter 1: HPMax%    - Maximum HP% That will trigger this Event to Expire (触发事件的生命值百分比上限)
Parameter 2: HPMin%    - Minimum HP% That will trigger this Event to Expire (触发事件的生命值百分比下限)
Parameter 3: RepeatMin - Minimum Time used to calculate Random Repeat Event Expire (重复检查的最小间隔时间，毫秒)
Parameter 4: RepeatMax - Maximum Time used to calculate Random Repeat Event Expire (重复检查的最大间隔时间，毫秒)

COMBAT ONLY - Expires when HP is between (Param1) and (Param2). Will repeat every (Param3) and (Param4).
This is commonly used for events that occur at a specific HP% Range (Such as Heal/Enrage Spells or NPC's that Flee).
NOTE: For Repeat Events the Repeat Timer ONLY Re-Check's Event Conditions to see If HP% Is Between Max and Min. If it is then Event will Expire again.
[仅战斗中] 当自身生命值百分比处于 (Param1) 与 (Param2) 之间时触发，每隔 (Param3)~(Param4) 重复。常用于特定血量区间事件（如治疗、狂暴或逃跑）。
注：对于可重复事件，重复计时器仅重新检查生命值是否仍处于 [Min, Max] 区间内，若仍满足则再次触发。

-----------------
3 = EVENT_T_MANA: (自身法力值百分比)
-----------------
Parameter 1: ManaMax%  - Maximum Mana% That will trigger this Event to Expire (触发事件的法力值百分比上限)
Parameter 2: ManaMin%  - Minimum Mana% That will trigger this Event to Expire (触发事件的法力值百分比下限)
Parameter 3: RepeatMin - Minimum Time used to calculate Random Repeat Event Expire (重复检查的最小间隔时间，毫秒)
Parameter 4: RepeatMax - Maximum Time used to calculate Random Repeat Event Expire (重复检查的最大间隔时间，毫秒)

COMBAT ONLY - Expires once Mana% is between (Param1) and (Param2). Will repeat every (Param3) and (Param4).
This is commonly used for events where an NPC low on Mana will do something (Such as stop casting spells and switch to melee).
[仅战斗中] 当法力值百分比处于 (Param1) 与 (Param2) 之间时触发，每隔 (Param3)~(Param4) 重复。常用于 NPC 低蓝时切换行为（如停止施法改用近战）。

------------------
4 = EVENT_T_AGGRO: (进入战斗/初始仇恨)
------------------
COMBAT ONLY - This Event Expires upon Initial Aggro (This Event does not occur again until NPC either Evades/Respawns and then Enters Combat Again).
[仅战斗中] 在首次获得仇恨进入战斗时触发（在 NPC 脱战或重生并再次进入战斗前不会再次触发）。

-----------------
5 = EVENT_T_KILL: (击杀单位)
-----------------
Parameter 1: RepeatMin - Minimum Time used to calculate Random Repeat Event Expire (重复冷却的最小间隔时间，毫秒)
Parameter 2: RepeatMax - Maximum Time used to calculate Random Repeat Event Expire (重复冷却的最大间隔时间，毫秒)
Parameter 3: PlayerOnly - Setting it to 1 will cause event only to trigger if the triggerer is a player. (设为 1 时仅当被击杀者为玩家时触发)

COMBAT ONLY - Expires upon killing a unit. Will repeat every (Param1) and (Param2).

=========================================
Cast Flags / 施法标志
=========================================
Below is the list of current Cast Flags that EventAI's spell casting can handle.
Cast flags are handled bitwise. Bit 0 is Interrupt Previous, bit 1 is triggered, etc.
So for example the number "3" (11 in Binary, selecting first 2 options) would mean that this cast has both CAST_INTURRUPT_PREVIOUS and CAST_TRIGGERED.
Another example: the number "5" (101 in Binary, selecting first and third options) would mean that this cast has CAST_INTURRUPT_PREVIOUS and CAST_FORCE_CAST.
以下是 EventAI 施法动作支持的施法标志（Cast Flags）列表，按位掩码处理。
例如 3（1+2）同时启用 CAST_INTURRUPT_PREVIOUS 与 CAST_TRIGGERED；5（1+4）同时启用 CAST_INTURRUPT_PREVIOUS 与 CAST_FORCE_CAST。

#   Decimal     Internal Name                       Description
--------------------------------------------------------------
1   1           CAST_INTURRUPT_PREVIOUS             Interrupts any previous spell casting (basicaly makes sure that this spell goes off)
    [中文] 打断之前的施法（确保当前法术能够顺利施放）
2   2           CAST_TRIGGERED                      Forces the spell to be instant cast and require no mana/reagents.
    [中文] 触发式施法（强制瞬发，且不消耗法力值和施法材料）
3   4           CAST_FORCE_CAST                     Forces spell to cast even if the target is possibly out of range or the creature is possibly out of mana
    [中文] 强制施法（即使目标超出射程或生物法力不足也强制施放）
4   8           CAST_NO_MELEE_IF_OOM                Prevents creature from entering melee if out of mana or out of range
    [中文] 缺蓝或超距时不进入近战（防止生物因没蓝或够不到而上前平砍）
5   16          CAST_FORCE_TARGET_SELF              Forces the target to cast this spell on itself
    [中文] 强制目标对自己施放该法术
6   32          CAST_AURA_NOT_PRESENT               Only casts the spell on the target if the target does not have the aura from that spell on itself already.
    [中文] 仅当目标身上尚未存在该法术光环时才施放
7   64          CAST_IGNORE_UNSELECTABLE_TARGET     Deprecated - Can target UNIT_FLAG_NOT_SELECTABLE
    [中文] 已弃用 —— 允许以带有 UNIT_FLAG_NOT_SELECTABLE 的单位为目标
8   128         CAST_SWITCH_CASTER_TARGET           Switches target and caster for spell cast - enables casting by spawner on AI owner for example
    [中文] 互换施法者与目标（例如让召唤者对 AI 拥有者施法）
9   256         CAST_MAIN_SPELL                     Marks main spell for ranged mode. When this spell is interrupted or goes OOM, the AI owner goes into melee mode. Connected to ACTION_T_SET_RANGED_MODE
    [中文] 标记为远程模式主法术：当该法术被打断或空蓝时，AI 将切入近战模式（配合 ACTION_T_SET_RANGED_MODE 使用）
10  512         CAST_PLAYER_ONLY                    To be used in connection with targets. Restricts targeting to player only
    [中文] 仅限玩家目标（与目标类型配合使用，限定只选玩家）
11  1024        CAST_DISTANCE_YOURSELF              Marks spell which stuns or immobilizes, so that creature distances itself from target, when main aggro target is hit (GetVictim()). Connected to ACTION_T_SET_RANGED_MODE.
    [中文] 拉开距离标记：用于昏迷或定身类法术，当主仇恨目标被命中时生物会与目标拉开距离（配合 ACTION_T_SET_RANGED_MODE 使用）
12  2048        CAST_TARGET_CASTING                 Selects only targets that are casting
    [中文] 仅选择正在施法的目标
13  4096        CAST_ONLY_XYZ                       Targets only coords of target and not unit
    [中文] 仅以目标坐标（XYZ）而非目标单位自身作为施法目标

NOTE: You can add the numbers in the decimal column to combine flags.
For example if you wanted to use CAST_NO_MELEE_IF_OOM(8) and CAST_TRIGGERED(2) you would simply use 10 in the cast flags field (8 + 2 = 10).
注：可将 Decimal 列的数值相加来组合多个标志位（例如 8 + 2 = 10）。
